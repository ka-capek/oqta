WHY NATIVE

We rewrote it in C++ so it stops paying for a browser.

Relay 0.5 was an Electron app. Chromium was most of its size and most of its memory, for a tool that barely needed it. 0.6 is the same app, every feature intact, on Qt 6.

FEATURES

The Git you use every day, without the account juggling.

An account per repository

Sign in with several GitHub accounts and pick which one each repository uses. Clone, fetch and push go out as the right person, every time.

SSH identities, no config edits

Save a key per host and choose it from the account menu. No sign-in needed, and your SSH agent and ~/.ssh/config stay one click away.

GitLab, Gitea and Forgejo too

Add GitLab.com or a self-hosted server with a read-only token and browse its repositories next to your GitHub ones.

The whole workflow

Merge, rebase, cherry-pick, stash, tags, branch compare and conflict resolution. Squash and reorder unpushed commits by dragging them.

Force push that checks first

Relay refuses to overwrite origin if someone pushed since your last fetch. Deleting a remote branch shows its last commit, so it can come back.

Fits your setup

Opens repositories in VS Code, Cursor, Zed, Sublime Text or JetBrains IDEs. Light, dark, mono and Catppuccin themes, or load your own palette.
